# design.md

## Brand Direction

A calm, editorial-style AI brand with a premium magazine aesthetic.

The design should feel:

* Minimal
* Atmospheric
* Softly luxurious
* Intelligent and modern
* Spacious and typographic

The website relies on:

* Off-white backgrounds
* Warm black typography
* Elegant serif headlines
* Soft pastel gradient atmospheres
* Subtle UI components
* Generous whitespace

Avoid startup-style neon gradients, aggressive colors, heavy shadows, or overly technical interfaces.

---

# Core Design Principles

## 1. Typography First

Typography is the brand.

Large elegant serif headlines create the identity.
UI chrome stays quiet and understated.

### Headline Font

Use:

* Waldenburg Light (preferred)
* EB Garamond (fallback)
* GT Sectra (alternative)

Headlines should:

* Use weight 300
* Never be bold
* Have tight letter spacing
* Feel editorial and refined

### Body Font

Use:

* Inter

Body text should:

* Stay readable
* Use weight 400–500
* Slightly increase tracking
* Feel calm and premium

# Color System

## Primary Colors

| Role            | Color     |
| --------------- | --------- |
| Background      | `#f5f5f5` |
| Main Text       | `#0c0a09` |
| Secondary Text  | `#4e4e4e` |
| Borders         | `#e7e5e4` |
| Card Background | `#ffffff` |

## Accent Philosophy

There is NO bright brand color.

The brand energy comes from:

* Photography
* Typography
* Atmospheric gradients

Buttons should remain near-black.

---

# Atmospheric Gradients

Use soft blurred radial gradients as decorative atmosphere only.

## Approved Gradient Colors

* Mint → `#a7e5d3`
* Peach → `#f4c5a8`
* Lavender → `#c8b8e0`
* Sky → `#a8c8e8`
* Rose → `#e8b8c4`

## Rules

* Never use gradients inside buttons
* Never use gradients for text
* Never use gradients as harsh backgrounds
* Keep gradients blurred and subtle
* Gradients should feel photographic, not graphic

---

# Layout Philosophy

## Spacing

Use large spacing throughout the site.

### Preferred Rhythm

* Section spacing: `96px`
* Card spacing: `24px`
* Small spacing: `16px`

The site should breathe.

Never overcrowd sections.

---

# Shapes

Use soft rounded geometry.

| Element                | Radius    |
| ---------------------- | --------- |
| Buttons                | Full pill |
| Cards                  | 16px      |
| Large feature surfaces | 24px      |
| Inputs                 | 8px       |

Avoid sharp corners.

---

# Buttons

## Primary Button

* Near-black background
* White text
* Pill shape
* Minimal styling

## Secondary Button

* Transparent background
* Thin border
* Black text
* Pill shape

Buttons should feel quiet and premium — not loud.

---

# Cards

Cards should:

* Use white surfaces
* Have soft borders
* Use minimal shadows
* Feel airy and elegant

Preferred shadow:
`0 4px 16px rgba(0,0,0,0.04)`

---

# Navigation

Navigation should:

* Be simple
* Stay lightweight
* Use small Inter text
* Avoid oversized menus
* Maintain lots of breathing room

---

# Hero Sections

Hero sections should include:

* Large serif headline
* Short supporting copy
* One primary CTA
* One secondary CTA
* Soft atmospheric gradient behind content

The hero should feel cinematic and calm.

---

# UI Tone

The interface should feel:

* Editorial
* Human
* Sophisticated
* Quietly futuristic

Avoid:

* Loud SaaS visuals
* Neon accents
* Heavy dark mode
* Dense dashboards
* Technical developer aesthetics

---

# Component Guidelines

## Good Components

* Soft cards
* Large typography
* Pill buttons
* Editorial layouts
* Spacious grids
* Minimal forms

## Avoid

* Hard shadows
* Sharp corners
* Bright CTA colors
* Over-animated UI
* Tiny dense text
* Overly colorful illustrations

---

# Responsive Behavior

## Mobile

* Headlines scale down significantly
* Grids collapse to single column
* Gradient atmospheres shrink
* Navigation becomes hamburger menu

## Desktop

* Wide breathing room
* Max width around 1200px
* Large typography remains dominant

---

# Overall Visual Reference

The site should feel like:

* A premium print magazine
* A cinematic AI brand
* Calm technology
* Atmospheric storytelling

The experience should prioritize:

1. Typography
2. Whitespace
3. Atmosphere
4. Subtle interaction
5. Elegant restraint

Not:

* Loud marketing
* Aggressive conversion tactics
* Bright startup aesthetics
